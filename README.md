# Ruta Incoterms 2020

Maqueta 3D interactiva para explicar en clase los **Incoterms® 2020** (ICC), pensada para Formación Profesional (Transporte Internacional de Mercancías).

## Qué incluye
- Los 11 Incoterms 2020, con **FCA Fábrica** y **FCA Terminal** por separado.
- **Modo explicación**: la mercancía recorre la ruta paso a paso (almacén, aduana, terminal, transporte principal, destino).
- **Transporte principal**: barco para los Incoterms marítimos (FAS, FOB, CFR, CIF) y tren o avión para los multimodales, con camiones en origen y destino.
- **Semáforo** de coste, riesgo y seguro en cada tramo (azul = vendedor, naranja = comprador). En CIF y CIP indica el seguro obligatorio ICC (C) / ICC (A) al 110 %.
- **Panel lateral**: paso actual, quién paga cada tramo y ficha de cada Incoterm.
- **Modo juego**: preguntas durante la ruta y «¿Qué Incoterm es?», individual o por equipos.

## Cómo abrirla
Abre `index.html` en un navegador actualizado (necesita conexión a Internet para cargar la librería 3D Three.js), o usa el enlace de GitHub Pages del repositorio.
